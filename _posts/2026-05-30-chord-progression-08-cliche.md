## クリシェ進行とは？半音下降が生む哀愁

コードを保持したままベース音だけが半音ずつ下降する。この「C/B♭ → C/B → C/A」という動きが「Michelle」（Beatles）や「津軽海峡・冬景色」の深い哀愁を生む。

**ベースライン例（Cキー）：ド → シ → シ♭ → ラ**

## アニソンでのクリシェ進行

半音ずつ下がるベースラインが生む「不穏さ」と「切なさ」は、アニメの劇伴・主題歌でも効果的に使われている。感情が静かに沈んでいく場面や、決意を固める緊迫したシーンとの相性が良い。

<div style="background:#eceae7;border-radius:8px;padding:1.2rem 1.4rem;margin:1.5rem 0;border-left:4px solid #1e3a5f;"><h3 style="color:#111827;margin-top:0;font-size:1rem;font-weight:700;">🎌 クリシェ進行とアニソンの相性</h3><p style="color:#111827;margin:0;">半音下降ベースは西洋クラシックの伝統技法だが、その「じわじわ来る」感情表現はアニメ音楽とも親和性が高い。<a href="/chord/chord-progression-06-kanashii/" style="color:#1e3a5f;text-decoration:underline;">切ない系進行</a>と組み合わせて使われることも多く、劇伴作家に好まれる技法のひとつ。</p></div>

## ギター・ベースでの弾き方

```
コード: C    C/B   C/B♭  Am
ベース: ド →  シ →  シ♭ → ラ（半音下降）
```

ベースラインを意識した伴奏が核心。左手（ピアノ）やベースギターで表現する。

## ピアノ・キーボードでの弾き方

左手で半音下降ベースを弾きながら、右手でコードを保持する：

```
C    : ド・ミ・ソ  （ベース: ド）
C/B  : ド・ミ・ソ  （ベース: シ）
C/B♭ : ド・ミ・ソ  （ベース: シ♭）
Am   : ラ・ド・ミ  （ベース: ラ）
```
